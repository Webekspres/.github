## Sebelum Membuka Issue

Cek hal berikut terlebih dahulu:

1. **Cari issue yang sudah ada** — mungkin masalah Anda sudah dilaporkan
2. **Baca dokumentasi** — periksa README repositori terkait atau [panduan deployment](DEPLOYMENT_GUIDE.md)
3. **Perbarui ke versi terbaru** — bug mungkin sudah diperbaiki di release baru

---

## Jenis Dukungan

### Bug Report

Gunakan template **Bug Report** saat membuka issue. Sertakan langkah reproduksi yang jelas agar tim dapat membantu dengan cepat.

### Feature Request

Gunakan template **Feature Request**. Jelaskan use case dan manfaat yang diharapkan.

### Pertanyaan Umum

Untuk pertanyaan yang tidak cocok sebagai issue (misalnya konsultasi proyek baru), hubungi kami melalui email atau website.

### Masalah Deployment

Untuk error saat deploy (DNS, SSL, Docker, Plesk, cPanel), ikuti [Panduan Deployment](DEPLOYMENT_GUIDE.md) dan bagian troubleshooting di dalamnya.

---

## Dukungan Klien

Klien yang memiliki kontrak maintenance aktif dapat menghubungi tim account manager masing-masing. Untuk pertanyaan billing atau kontrak, gunakan kanal komunikasi yang sudah disepakati dalam kontrak proyek.

---

## Waktu Respons

| Prioritas | Target Respons |
|-----------|----------------|
| Kerentanan keamanan | 24 jam |
| Bug kritis (production down) | 4–8 jam kerja |
| Bug non-kritis | 2–3 hari kerja |
| Feature request | 5 hari kerja |
| Pertanyaan umum | 3–5 hari kerja |

> Waktu respons di atas adalah target untuk hari kerja (Senin–Jumat, WIB).
